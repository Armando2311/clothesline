# Clothesline premium experience

Implement the ten approved recommendations on codex/clothesline-premium-experience; never merge or push main. Keep macOS 13 support and the local, original-preserving file model. No paywall or hosted uploads.

1. Reliable handling: observable added/duplicate/error feedback, durable board saves, recovery of owned copies and unavailable references.
2. Adaptive presentation: optional fitted width centered on the display, full-width alternative, card sizing; optional No Theme empty-space clickthrough without losing drag targets.
3. Contextual toolbar: focused primary actions, secondary More menu, stable Pin/Settings/EXIT.
4. Collection gestures: insertion feedback, batch count, grouping, destination-line drop affordances; retain existing Finder-compatible exports.
5. Export workflows: named presets with bookmarked destinations, formats, image byte limits, accurate filename preview and asynchronous size estimates.
6. Collection rules: optional kind/source/folder routing with matching preview, enabled/pause controls, stable-file checks and restart deduplication.
7. Workspaces: per-line destination, export preset, organization and grouped/pinned items retained across launches.
8. Search actions: kind/source/line/date filters, highlighted matches, OCR text copy and original location actions.
9. History: bounded durable addition/removal/export snapshots, restore to line, show outputs and repeat export; never promise recovery of deleted user originals.
10. Native finish: accessible controls, Reduce Transparency treatment, onboarding walkthrough, update checking, signed/notarized release tooling. Actual notarization requires a Developer ID identity and stored notary credentials; never fabricate success.

Verification: regression tests for persistence/migration, ownership safety, filters/date boundaries, adaptive geometry, rules, recovery and export semantics; complete Swift suite and Xcode build; sample-state live UI checks and rendered preview. Release tooling validated locally without transmitting/signing with absent credentials.
